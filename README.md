# DEADBALLS 2 — Build 0.1.0

**Studio:** Mad Purple Hat Games  
**Target retail price:** **$8.99**  
**Format:** Standalone HTML5 Canvas browser game

## Included
- Wave-based zombie survival arena with escalating difficulty
- Four regular enemy types plus a boss every fifth wave
- Three weapons: Sidearm, Breacher shotgun, Ripper automatic rifle
- Reloading, ammo reserves, health, XP/level-ups, score, pickups and dash
- Desktop keyboard/mouse and touch controls
- Fullscreen toggle, pause, restart, game-over screen and synthesized sound effects
- No external game engine, API key, backend, or paid asset dependency

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For local-server testing, run from this folder:
   `python3 -m http.server 8080`
4. Open `http://localhost:8080`.

## Controls
- **Desktop:** WASD or arrow keys to move; mouse to aim and fire; `R` reload; `1`, `2`, `3` switch weapons; `Space` dash; `Esc` pause.
- **Mobile:** left virtual pad to move; FIRE to shoot; DASH to evade; 1/2/3 to change weapons; R to reload.
